# AI Summarizer App

An AI-powered text summarizer web app. Paste long articles, documents, or notes and get a concise summary instantly.

> **Status:** This repository is a starter scaffold — the full app code is not yet committed.

## Planned features

- Paste text or upload documents (TXT, PDF, Markdown) for summarization
- Adjustable summary length (short / medium / detailed)
- Copy-to-clipboard and download-summary options
- Clean, responsive UI

## Tech stack (planned)

- Frontend: Next.js / React + Tailwind CSS
- AI: LLM API (NVIDIA NIM / OpenAI-compatible endpoint)

## Getting started

```bash
npm install
npm run dev
```
